# MyLink (마이링크)

나만의 링크트리 클론 — 프로필과 여러 링크를 한 페이지에 모아 보여주는 서비스입니다.
「아이디어를 현실로: 바이브 코딩」 수업 과제입니다.

- 저장소: https://github.com/luzel5798/mylink
- 배포 주소: https://luzel5798.github.io/mylink/

## 구성
- `index.html` — 프로필(이름, 소속, 소개글)과 링크 목록을 보여주는 반응형 페이지 (다크 모드 지원)

## 수정 방법
- 프로필: `index.html`의 `<section class="profile">` 부분을 수정
- 링크: `index.html` 아래쪽 `links` 배열에서 제목(`title`)과 주소(`url`)를 수정하거나 한 줄씩 추가
